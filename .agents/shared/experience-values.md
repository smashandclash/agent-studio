# Experience Values

This project adopts shared product/UX values inspired by:

- `guidelines.sh` (craft-oriented interface guidance)
- Benji Taylor's "Family Values" (`benji.org/family-values`)

These values apply across `.claude`, `.agents`, and `.cursor`.

## Core Principles

1. **Simplicity**
   - Prefer gradual revelation over dumping all controls at once.
   - Keep complexity hidden until it becomes relevant.
   - Respect cognitive load in high-risk flows (onboarding, purchase, confirmation).

2. **Fluidity**
   - Use transitions to preserve orientation and spatial continuity.
   - Motion must communicate where users came from and where they are going.
   - Avoid disjoint jumps that feel like teleportation between states.

3. **Delight (Selective)**
   - Add craft moments intentionally, especially in infrequent/high-emotion flows.
   - Use subtle surprises and microinteractions, not constant novelty.
   - Prioritize trust, clarity, and confidence over spectacle.

## Practical Design Standards

- Keep visual systems constrained (palette, radius, typography, motion curves).
- Favor subtle feedback over loud effects (hover, focus, shadows, animation).
- Design all interface states: loading, empty, error, partial, success.
- Respect accessibility and reduced motion preferences by default.
- Choose consistency in product surfaces; reserve bold asymmetry for marketing surfaces.
- Optimize perceived speed and real speed together (smooth transitions + performance).

## Product Integrity

- Utility, performance, and security are table-stakes.
- Craft is cumulative: many small details produce a trustworthy product feel.
- Build for repeat usage (the 100th interaction), not just first impression.
